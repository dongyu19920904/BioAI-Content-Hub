# 后续网站的轻量流量统计标准

更新：2026-09-29。适用于本项目之后新建的公开项目网站和网页；不适用于私人健康数据、订单或用户行为明细的公开展示。

## 当前选择

优先复用已有的 **51.LA V6**，不在同一页同时装多个统计 SDK。`life.aivora.cn` 已在 `src/layouts/Layout.astro` 载入一次统计脚本、在 `src/components/Footer.astro` 展示一次公开计数；因此同一布局下的新文章和项目页无需逐页粘贴代码。`/stats/` 解释计数口径。其他独立域名要在 51.LA 后台新建站点统计应用，取得**该站点自己的 ID**，不要直接复制本站 ID 混合多站数据。

服务商当前列出的基础免费额度为 30 个统计 ID、每月 300 万 PV、每月 1 万事件和每月 100 次数据 API 请求；这些是服务商公布的上限，日后可能调整，新增站点前重新核实。[51.LA 官方价格与功能](https://v6.51.la/)及[安装帮助](https://v6.51.la/help-doc/)是准绳。若项目以后超出免费额度，先停增量调用并决定是否换方案，不自动购买扩容。

## 新网站接入步骤

1. 在 51.LA V6 新建应用，填项目名和**真实生产域名**，开启域名匹配。服务商文档提醒，不匹配的域名可能不采集；预览域名和本地开发不应混入正式统计。
2. 将该应用给出的统计 ID 配到站点的共同布局，整站只载入一次服务商正式脚本。本站的 Astro 接法可参考 `src/config.ts` 与 `src/layouts/Layout.astro`；其他框架按服务商提供的异步/Spa 接法配置，不能假定客户端跳转自动记页。

   对没有框架的普通 HTML，可将后台生成的正式代码放到共同模板的 `</head>` 前。本站当前使用的 V6 形式如下，`YOUR_SITE_ID` 必须替换为**新站点自己的 ID**，不要复制 `life.aivora.cn` 的 ID：

   ```html
   <script id="LA_COLLECT" src="https://sdk.51.la/js-sdk-pro.min.js"></script>
   <script>
     LA.init({ id: "YOUR_SITE_ID", ck: "YOUR_SITE_ID", autoTrack: true, hashMode: false });
   </script>
   ```
3. 测试首页、文章页和工具页是否只有一个统计脚本，并到后台核对相应页面路径。测试会产生自己的访问，验收记录应标记为自检；不要把自检当作自然流量。
4. 若希望用户直接看详细数据，在后台生成**只读报表分享链接**，确认不会泄露访客明细、IP、邮箱或私人查询参数，然后填入站点配置的 `publicReportUrl`。当前本站此项仍为空，页面诚实标为未公开。绝不把管理员登录、Cookie 或 API Key 放在前端。
5. 若希望 AI 自动分析，每日最多一次从服务商**正式数据 API**拉取聚合报表；令牌放在仓库受限 Secret，公开只写站点/页面的聚合数、日期、来源及统计口径，不写访客明细。没有正式 API 授权或只读报表链接时，AI 报告为“数据未知”，不爬后台或把公开挂件当作逐页数据。

## 只记录能帮助做决定的指标

| 问题 | 指标 | 决策与边界 |
| --- | --- | --- |
| 哪篇内容有人找到？ | 页面路径、按日 PV、来源 | 与公开教程/项目发布日期对照；搜索机器人、自检和浏览器拦截会影响数字 |
| 内容有没有带到工具？ | 文章到项目/初筛入口的匿名点击事件 | 需先按服务商正式事件功能验证能采集，再定义事件；不存点击者身份 |
| 工具是否真的有需求？ | 非测试的公开申请数、合格复现反馈数 | GitHub Issue 计数独立于 PV；一次申请不等于一个独立客户 |
| 是否赚到钱？ | 实际订单、退款、服务成本、净额 | 未来有合规收费链后单独计算；流量平台不能证明收入 |

项目公开链接或文章 URL 不要拼接健康信息、邮箱、API Key 等个人内容。公开报表只展示聚合项。用户和 AI 应能分清“页面被访问”“完成任务”“付费购买”，不得互相代替。

## 可替代方案

如果没有 51.LA 账号或需要开源方案，优先看 [GoatCounter](https://www.goatcounter.com/)：官方当前为合理使用量提供免费托管，允许小型商业站点，脚本轻，可选择公开仪表盘，并提供[统计 API](https://www.goatcounter.com/help/api)。但**每个域名应创建独立站点**，否则同名路径会混在一起；见[官方多站说明](https://www.goatcounter.com/help/domains)。接入时先取得用户的站点账号/项目代码，不能凭空宣称已采集。Cloudflare Web Analytics 同样免费且有轻量脚本，但公开分享给访客与 AI 读取需要额外配置，作为备选而非叠加安装。
