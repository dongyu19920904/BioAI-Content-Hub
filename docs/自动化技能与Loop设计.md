# 自动化技能与 Loop 设计

## 目标

把「AI 延续学商机日报」自动变成「文章 + 资料包 + 发布提交」。

建议拆成 4 个协作技能。

## Skill 1：商机筛选器

职责：

- 读取当天 AI 延续学商机日报。
- 提取 3-5 个候选选题。
- 按目标用户、痛点强度、可交付物、变现可能、合规风险评分。
- 只输出当天最值得做的 1 个主题。

输出：

```json
{
  "topic": "父母记忆力变差的 7 天观察清单",
  "target_user": "担心父母认知变化的子女",
  "deliverable": "文章 + 观察表 + 沟通话术",
  "risk": "不能暗示诊断痴呆",
  "reason": "痛点明确，容易传播，适合资料包"
}
```

## Skill 2：文章写手

职责：

- 把选题写成 1000-1800 字中文文章。
- 面向普通读者，不写论文摘要。
- 结构必须有：问题、为什么重要、怎么做、边界、资料包入口。
- 保留来源链接。

输出：

- Astro Markdown 文章
- frontmatter
- tags
- description

## Skill 3：资料包制作器

职责：

- 根据文章主题生成资料包草稿。
- 资料包必须是可复制、可下载、可售卖的交付物。

输出：

- 清单
- 表格
- 提示词
- 家人沟通话术
- 商品标题和详情雏形

## Skill 4：发布器

职责：

- 把文章写入 `src/data/blog/`
- 把资料包条目写入 `src/data/resourcePacks.ts`
- 运行构建检查
- 提交到 GitHub
- 后续触发 GitHub Pages 部署

## Loop 设计

```text
每天 09:30
  -> 拉取日报
  -> 商机筛选器
  -> 文章写手
  -> 资料包制作器
  -> 发布器
  -> 记录日志
```

失败策略：

- 如果没有合适选题：只生成一条「今日不做」记录。
- 如果来源不足：先生成待人工确认草稿，不自动发布。
- 如果涉及医疗高风险：只能生成资料整理，不生成销售型文案。

## 是否需要加 Skill

需要。

原因是这不是单次写作任务，而是每日重复流程。Skill 可以把判断标准固定下来，避免每天随机发挥。

但第一阶段不需要复杂 agent 系统，只需要：

- 4 个技能说明
- 1 个 loop 脚本
- 1 个 GitHub 提交流程
- 1 个人工审核开关

跑顺以后，再接更复杂的 CowAgent 多代理。
